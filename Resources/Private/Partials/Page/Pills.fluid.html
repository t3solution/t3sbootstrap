Same id as Page/Section on purpose: the scrollspy and the anchor scrolling in Page/Assets both key off #sectionmenu, so only the presentation differs here - a numbered pill that shows its title on hover and on keyboard focus, while the section currently scrolled to is marked by colour alone. The number is a CSS counter, not the loop index: the loop skips elements without a header, and f:for would count those as well. No sticky-top and no inline top here: the menu is positioned fixed and centred vertically in the stylesheet, so it floats at the edge of its column instead of scrolling with it. Both would fight that.
