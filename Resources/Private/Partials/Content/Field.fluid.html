Outputs a single field. With EXT:visual_editor, it remains at f:render.text—the editor needs the output via the Record object to set its markers. Without the editor, the raw value passes through f:sanitize.html so that simple markup in the header is preserved instead of being escaped. Intended ONLY for fields of the “input” TCA type. For an RTE field, f:sanitize.html would skip the parseFunc run, and t3:// links would remain unresolved. Expected: record, data, field {visualEditor} comes from the BootstrapProcessor. NOTE ON WHITESPACE: everything between and is deliberately on a single line. Fluid outputs the text around a ViewHelper verbatim, so a line break before would end up in the result. Callers store that result in a variable and check it with f:if—and a string of blanks is TRUE. That is how an empty supraheader ended up rendering

with nothing in it. Keep this line unbroken. {record -> f:render.text(field: '{field}', optional: true)}{data.{field} -> f:sanitize.html()}
